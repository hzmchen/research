# Berlin Traffic Data — Groundwork

> 🤖 Generated by a coding agent (Claude Code) via web research. Source links are
> provided throughout; figures and API details should be re-verified before
> operational use. Last updated: 2026-05-31.

A comprehensive survey of **traffic and mobility data for Berlin**, across all
modes and all provenance tiers (official, public/open, unofficial, private),
with ratings for **access, quality, usability, and coverage**.

## Why this exists

Berlin's mobility data is scattered across a city open-data portal, a dedicated
traffic-management platform, federal data spaces, transit-association feeds,
volunteer-run API wrappers, and commercial providers. This groundwork maps that
landscape so a project can quickly decide *where to get what, under which
licence, and how good it is*.

## Rating scheme

Each source is rated on four axes, scored **★☆☆ (low) · ★★☆ (medium) · ★★★ (high)**:

- **Access** — how easy/cheap/open is it to obtain? (open download > free API w/ key > registration/contract > paid > on-request only)
- **Quality** — accuracy, granularity, freshness, documentation, completeness.
- **Coverage** — spatial + temporal + modal extent within Berlin.
- **Usability** — machine-readability, standard formats, API ergonomics, licence permissiveness.

Provenance tags: **🏛 Official** (govt/agency) · **🌐 Open** (public open-data) ·
**🤝 Unofficial** (community/volunteer) · **🔒 Private** (commercial).

## Method & caveats

- Compiled from public web sources (May 2026). Each section ends with a **Sources** list.
- Quantitative figures (counts of sensors, record dates) reflect what sources stated and may drift.
- "Unofficial" wrappers can break when upstream APIs change; treat availability as best-effort.

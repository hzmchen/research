# City-development regulations

> 🤖 Generated by a coding agent — not human-verified.

Research topic on the regulations that govern urban development. First focus:
**road planning regulations in Berlin, Germany** — specifically, when a
four-lane traffic layout (*vierstreifige Verkehrsführung*) is **necessary** or
**allowed**.

## Question & boundaries

- **In scope:** the legal and technical framework that determines lane counts
  for Berlin streets — federal statutes (FStrG, UVPG, StVO), Berlin statutes
  (Berliner Straßengesetz, Mobilitätsgesetz), planning instruments (StEP MoVe,
  übergeordnetes Straßennetz, Landesstraßenplan), and the FGSV technical rule
  set (RIN, RASt 06, RAA, RSA 21, HBS); plus current Berlin cases (TVO, A 100,
  pop-up bike lanes).
- **Out of scope (for now):** other cities/Länder, parking and building
  regulations, detailed noise/air-limit numbers, historical evolution of the
  rule set.

## Method

Web search plus direct retrieval of primary sources (statute texts on
gesetze-im-internet.de, official Berlin Senate publications, planning-procedure
records). Quotes are tagged with a validation level:

| Tag | Meaning |
|-----|---------|
| **[V]** | Verbatim — the source page/PDF was fetched directly on the research date and the quote extracted from its text. |
| **[S]** | Sourced via search-engine result content attributed to the cited URL; the page itself was not separately re-fetched. Treated as reliable only when consistent with other evidence. |

No quote is reproduced from model memory alone; statutory texts were fetched
before quoting. Sources are graded for credibility:

| Grade | Definition |
|-------|-----------|
| **A** | Statute text on an official portal, or official government/Senate publication |
| **B** | Legal-database rendering of a statute, institutional project page |
| **C** | Reputable trade/legal press, advocacy-group monitoring, unofficial statute mirror |
| **D** | Wiki, personal site, forum |
